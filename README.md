# CMB — Company Profile

Website company profile CV. Chandra Maju Bersama (React + Vite).

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # hasil di folder dist/
```

Semua teks, produk, dan link ada di `src/data/content.js`.
Ilustrasi produk (SVG) ada di `src/components/Art.jsx` dan bisa diganti foto asli.
